## Codebase Patterns
<!-- Patterns accumulate here -->

- **Connection Model Pattern**: Unified connections table stores all integrations with encrypted credentials and JSON metadata. Legacy code uses backward-compatible accessors (e.g., `getAccessTokenAttribute()` returns `$this->credentials`).
- **Migration Pattern**: When migrating data from legacy tables, use `JSON_EXTRACT(metadata, '$.legacy_id')` to identify migrated records for safe rollback without affecting newer connections.
- **Filament Settings Pages**: Settings pages extend `Page` and use `getHeaderActions()` for connect/disconnect buttons. Connection status displayed via infolists, forms use modal actions for new connections.
