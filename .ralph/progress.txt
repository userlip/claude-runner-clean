## Codebase Patterns
- Use Pest for all tests, not PHPUnit
- Auth login redirect for Filament panel is `/admin/login` (not `/login`)
- Factory users can access `/admin` (returns 200) — no role required by default
- `/app` route lives in `routes/web.php` under `middleware(['auth'])->prefix('app')` group
- Spatie Permission role middleware registered in `bootstrap/app.php` with alias `role` — use `middleware(['role:admin'])` on routes
- Livewire full-page components use `resources/views/components/layouts/app.blade.php` (with `{{ $slot }}`) as default layout
- Mary UI table uses `headers` array + `rows` (paginator or collection) + `:sort-by` binding with `with-pagination` prop for built-in pagination
- Mary UI `<x-select>` expects options as array of `['id' => value, 'name' => label]` — use `->map(fn($case) => ['id' => $case->value, 'name' => $case->label()])` for enums
- For models with `uuid` route key, pass `uuid` as mount param and load via `Model::where('uuid', $uuid)->firstOrFail()`
